# Iowa Tequila Market Entry | 2021

**Iowa retailers bought 9.7% fewer tequila bottles in July 2021 than in June, even with the Fourth of July on the calendar.**

June recorded 153,193 bottles; July recorded 138,302. Did retailers place their holiday orders earlier? The monthly data raises that question but cannot answer it. I would check weekly orders, store checkout sales, and inventory before changing a forecast.

In this historical portfolio case, I take the role of a demand forecast analyst evaluating a retail pilot for a fictional tequila supplier at year-end 2021. I use public retailer purchase records to size the category, compare bottle quantities with purchase dollars, and identify stores for buyer conversations. The analysis does not describe current market conditions or establish recurring seasonality.

Tequila represented **$34,584,491.25**, or **8.08%**, of the **$428,123,535.40** in recorded 2021 spirits purchases. Its **1,616,872 bottles** include different bottle sizes. Dollar share measures purchase value; bottle counts measure units and are not equivalent to liters.

## Why I present the data this way

I start with the July observation because it connects a visible change to a planning decision. The overview establishes category scale, then pairs monthly bottles with wholesale dollars to distinguish unit movement from value movement. Different bottle sizes, product mix, and prices can affect that relationship. The two axes have different units; line height and bar height should not be compared directly.

The second page shows the retailer screen and the information I would request before committing inventory. A store buying less tequila than the statewide dollar mix is a candidate for investigation; that difference does not prove unmet demand or predict supplier revenue.

## How the headline is calculated

```text
Month-over-month bottle change = (July bottles - June bottles) / June bottles
                              = (138,302 - 153,193) / 153,193
                              = -9.7204%, rounded to -9.7%
```

The denominator is June because it is the comparison baseline. These are calendar-month purchase totals, not daily purchase rates. They measure retailer purchases from the state, not consumer checkout sales. Earlier holiday ordering is a hypothesis, not a measured cause.

## Reproduce the portfolio snapshot

Download the source ZIP from the [Kaggle dataset](https://www.kaggle.com/datasets/gabrielramos87/iowa-sales-liquor-jan-2021jan-2022). Run from this project folder using Python 3; the scripts use its standard library.

```text
python build_market_data.py "Iowa Liquor Sales (Jan 2021-Jan 2022).csv.zip" Iowa_Market_Entry_2021.json
python build_market_report.py
```

The first command filters to 2021, groups categories, and aggregates months and stores. The second writes the portfolio PBIP and its report/model folders; it does not create or update the PBIX. Open the PBIP in Power BI Desktop and save/export the PBIX separately after checking the report. Rebuilding replaces generated project definitions, so preserve manual report edits first.

The portfolio model embeds aggregate tables through Power Query M. Its chart measures sum those tables. Headline cards, quarter comparisons, and account text are generated by Python as fixed text; they do not recalculate when a chart is selected. This is a documented historical snapshot, not a live forecasting model. Updating the source requires rebuilding and checking the report.
